# 资料筛选与沉淀原则

这个知识库后续会持续吸收外部资料，但不会做“原文搬运站”。本文定义后续入库标准。

## 1. 收录标准

优先收录这些内容：

- 与 Agent 开发全链路强相关
- 结论清晰，不是纯情绪表达
- 有明确工程价值
- 能和已有知识体系接上
- 具备相对稳定的正确性

## 2. 降权内容

以下内容可以参考，但不直接高优先级入库：

- 纯 marketing 文案
- 只有概念包装、没有机制解释
- 只讲框架 API，不讲设计权衡
- 只展示 demo，没有失败条件和边界
- 明显过时或结论无法验证的文章

## 3. 入库处理方式

每次处理外部资料时，优先做这几步：

1. 判断主题归属
2. 提取高价值观点
3. 删除重复和噪声
4. 修正含混或可疑表述
5. 改写为知识库统一结构
6. 补充工程视角和实践建议

## 4. 文档组织原则

优先按“问题域”组织，而不是按“文章来源”组织。

例如：

- 不写“某某文章学习笔记 01”
- 优先写“Agent Loop 设计”“Harness 是什么”“Tool 设计原则”

这样更适合长期维护与检索。

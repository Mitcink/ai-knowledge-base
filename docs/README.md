## 维护约定

- 优先沉淀可复用、可验证、可落地的内容
- 不直接堆原始材料，先筛选、纠错、重组，再入库
- 每篇文档尽量同时回答三个问题：
  - 这是什么
  - 为什么重要
  - 工程上怎么落地
- 每一批内容都尽量附带一个可执行的学习或搭建任务

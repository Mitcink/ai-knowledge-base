知识库工作台

用一个统一界面完成资料导入、索引同步、知识问答和文档治理，逐步靠近一个可长期维护的个人知识产品。

API 文档

向量片段 - 当前知识库中切片总量，用于判断索引规模

知识库问答

基于已索引资料回答问题，并返回可核对的引用片段。左侧负责提问，右侧负责阅读和核对。

回答

优先给出简洁结论，必要时说明不确定性。

还没有回答，先提一个问题。

引用片段

每条引用默认折叠为摘要，避免整块长文本把界面撑坏。

回答后会在这里显示引用片段。

导入与同步

长期资料建议放进 data/raw/ 并批量同步，零散文档可直接上传并即时入库。

批量同步目录

扫描 data/raw/ 下所有支持格式文件，并重建或覆盖对应索引。
